# Structure library (script-writer agent picks one per video, rotation rule in .claude/agents/script-writer.md)

Each structure = a different viewer experience. Same facts, different shape. id | when it fits | beat outline.

| id | Fits | Beats (long video; a Short uses the first 3-4 beats compressed) |
|---|---|---|
| `deadline-countdown` | compliance dates (UAE / ZATCA / GST) | date + days left -> who is hit -> cost of missing -> 3 actions this week -> setup in Zoho -> checklist |
| `mistakes-to-avoid` | how-tos people get wrong | "N mistakes that cost you X" -> each mistake: symptom, why, fix on screen -> the one people miss -> checklist |
| `myth-vs-fact` | confusing rules (PDF is not an e-invoice) | the myth everyone believes -> 3-5 myths, each busted with the official source -> what is actually true -> action |
| `news-impact-action` | fresh news / launches | what happened (24 h) -> why it matters to you -> who wins / loses -> what to do now -> what to watch next |
| `before-after-demo` | a feature / automation | the painful "before" (time / money) -> the "after" result first -> build it step by step on screen -> numbers |
| `case-story` | partner / customer stories | one business + its problem -> the turning point -> what they set up -> result (only sourced numbers) -> copy it |
| `comparison-verdict` | X vs Y (plans, apps, MCP servers) | the decision people face -> criteria -> round by round -> verdict per type of business -> how to switch |
| `rapid-faq` | topics with many questions | the top 5-7 real questions (Google "People also ask" / forums) answered fast, one card each -> the hard one last |
| `step-by-step-tutorial` | pure evergreen setup | result preview -> prerequisites -> numbered steps on real screens -> test it -> common error + fix |
| `teardown-explained` | big business / tech news (Nvidia style) | the headline number -> break it into 3 parts -> the part the headlines missed -> what it means for small businesses |
| `challenge-build` | AI + Zoho (Claude / MCP) | "I tried to do X in 10 minutes" -> attempt -> snag -> fix -> final result + time taken |
| `timeline-update` | follow-ups on topics we covered | what we said last time -> what changed (new decision / date) -> new timeline -> who must act now |

Hook types to rotate: number, question, mistake, news, contrarian, story, result-first.
